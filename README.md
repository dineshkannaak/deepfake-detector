#  AI Image Detector

An AI system that detects whether an image is real or AI-generated.

## Tech Stack
- EfficientNet B0 (Transfer Learning)
- PyTorch + torchvision
- Gradio web interface
- Deployed on Hugging Face Spaces

## Live Demo
[try it here](https://huggingface.co/spaces/dk7706/deepfake-detector)

## Model Performance
- Test Accuracy: 97.72%
- AUC Score: 0.9972

## Dataset
CIFAKE — 120,000 real and AI-generated images
